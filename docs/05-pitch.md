# Pitch (3 minutos)
 
## Roteiro Sugerido

### 1. O Problema
> Pessoas comuns têm dificuldade em entender sua própria situação financeira: não sabem se estão gastando demais, não conhecem os produtos de investimento disponíveis para o seu perfil e acabam tomando decisões sem orientação adequada.

### 2. A Solução
> O Bob é um assistente financeiro conversacional desenvolvido em Python com Streamlit e Ollama rodando localmente. Ele utiliza três fontes de dados, perfil do cliente, histórico de transações e produtos financeiros para gerar respostas personalizadas e seguras. Os produtos são filtrados automaticamente pelo perfil do investidor antes de qualquer recomendação, e o agente é instruído via prompt a responder somente com base nos dados disponíveis, sem inventar informações.

### 3. Demonstração
> Três cenários foram demonstrados na prática: Ao perguntar se está gastando muito, ele analisa o histórico de transações e gera uma resposta baseada nos dados reais. Quando perguntei sobre Bitcoin o agente informa que não possui essa informação porque ela não está na base de dados. E ao pedir uma recomendação de investimento, o sistema usa o perfil do cliente como a Maria, conservadora, com renda de R$ 3.200 — para sugerir apenas produtos de baixo risco.

### 4. Diferencial e Impacto
> O diferencial do Bob está na segurança: ele não alucina. Tudo que responde vem dos dados do próprio cliente. O projeto demonstra como IA generativa pode auxiliar decisões financeiras de forma acessível e confiável.
